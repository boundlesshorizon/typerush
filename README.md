# TypeRush — Free Typing Speed Test

Live URL: https://typerush.app (after deploy)

## Features
- Real-time WPM + accuracy + streak tracking
- 4 time modes: 15s, 30s, 60s, 120s
- 4 difficulty levels: Easy, Medium, Hard, Code
- Infinite word stream
- Mobile responsive
- Full SEO: sitemap, robots, OG tags, JSON-LD schema
- PWA ready

## Deploy to Vercel

1. Push to GitHub
2. Connect repo on vercel.com
3. Deploy — zero config needed

## After Deploy

1. Replace `REPLACE_WITH_YOUR_GOOGLE_VERIFICATION_CODE` in `app/layout.js`
2. Submit sitemap to Google Search Console: `https://typerush.app/sitemap.xml`
3. Apply for Google AdSense after 4 weeks of traffic

## Local Dev
